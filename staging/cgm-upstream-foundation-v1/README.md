# CGM Phase 40CC — upstream foundation, not a session issuer

**State:** Staging-only PHP source for a fail-closed CGM-owned relay foundation. Original APK, Nox62033, rollback Nox62030, production backend and default GitHub branch remain unchanged.

This package applies earlier verified native/client and archive observations without fabricating external VIP entitlement or PlayPark/GameServer/GardenServer authorization.

- **Original envelope:** decrypted `packetHex~stage~relaySession`; LE16 frame length, per-Session LE32 packet counter, known Stage0 command `01 01`, and six verified Stage1 categories `00 16`, `01 00`, `0A 00`, `1F 0C`, `09 00`, `00 00`. The parser never records/returns packet bytes, original credentials, packet counter, or relay string.
- **Historic Stage0:** some requests have existing relay state, so do not require an empty Stage0 token. Relay-state presence is **not** authorization.
- **Historic Stage1:** requests may be concurrently in-flight; the test-only request ledger demonstrates unique per-attempt/per-request correlation and stale/replay rejection, not a durable real server implementation.
- **Original response:** Unity 2021.3 `JsonUtility.FromJson<T>` into `MGRelayResponse` with `servertype:int` and `vip_expiry:uint`. The archive's `servertype=null` field reflects PHP diagnostic type collapse; it is not evidence of a missing, integer, string, or float original value. Do not silently default a supposed positive game reply.
- **Official game acceptance:** original upstream output transformation/issuance remains unknown. The earlier `ZeroTransformRelayCandidate` is explicitly unproven and incomplete for Stage1. No fake `error=false`, userSN, CCU, accepted Game/Garden packets or game sessions are generated by this code.
- **Credential privacy:** protected `GET ?data=` can contain reversible credential material. No packet URLs or secrets are logged. The HTTP `session.php` stub returns **503** and never reads/forwards the query; the dry-run PHP function returns **only `error=true`** to local synthetic fixtures.

**Test evidence (authoring environment, not Windows/Nox):** `php -l` for seven PHP files, `PHASE40CC_UPSTREAM_FOUNDATION_OFFLINE_PASS assertions=163`, local HTTP smoke `health=200 /session.php=503`, ZIP CRC and per-file SHA verification. The full source/test/Unity synthetic probe package is `CGM_Phase40CC_Upstream_Foundation_OFFLINE.zip` (18,574 bytes; SHA256 `adcec70526eaf5199d7fe86951d4e25841e923991913b0eb1ea544a47a641f1d`). The ZIP is a conversation artifact, not deployed from GitHub. The optional Unity `ResponseTypeProbe.cs` is not yet run.

**Remaining real prerequisite:** an approved compatible upstream/provider contract that attests the official account, issues/validates authentic sessions, handles every required command and overlapping request correctly, and supplies actually accepted game/Garden responses. CGM ACTIVE membership alone is insufficient.
